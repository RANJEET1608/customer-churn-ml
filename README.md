# Customer Churn Prediction

This project focuses on predicting customer churn using Machine Learning models. I built this project to understand how businesses can use customer data to identify customers who are likely to leave a service.

The project includes data preprocessing, exploratory data analysis, visualization, model training, and prediction using classification algorithms. The main purpose of this project was to understand customer behavior patterns and build a predictive model that can help businesses improve customer retention.

In this project, I worked on the complete Machine Learning pipeline starting from data preprocessing, data analysis, visualization, model building, and prediction.

---

## Dataset

The dataset contains customer-related information such as:
- Customer demographics
- Tenure
- Monthly charges
- Contract type
- Payment method
- Internet service
- Churn status

---

## What I Did in This Project

- Cleaned and processed the customer dataset
- Performed Exploratory Data Analysis (EDA)
- Visualized customer churn patterns
- Applied feature engineering techniques
- Built multiple Machine Learning models
- Compared model performance using evaluation metrics
- Predicted customer churn using classification algorithms
